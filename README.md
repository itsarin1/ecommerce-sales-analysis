# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to identify sales trends, top-performing products, and customer purchasing behavior.

## Business Questions
1. Which products generate the highest revenue?
2. How does revenue change over time?
3. Which customers contribute the most sales?

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboard

## Dataset
Superstore Sales Dataset from Kaggle

## Key Insights
- Top-selling products contributed significantly to total revenue.
- Sales showed strong growth during year-end periods.
- A small percentage of customers contributed a large share of sales.
